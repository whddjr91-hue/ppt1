# 2세션 고급 도구 추가 지침

기존 독립 검수 역할과 원본 비편집 원칙을 유지한다. `advanced-tools.json`과 `docs/고급도구추가.md`를 읽는다. 현재 내장 PDF 스킬을 우선 재사용하고, 공식 고정 원본은 `vendor/skills/openai-pdf/SKILL.md`에서 확인한다. 텍스트 추출과 전 페이지 PNG 시각 검수를 구분한다. 원고 누락·삭제표시·화자·조건·페이지별 #1 싱크·도식 구조·자료 매핑·출처·읽기성·잘림·겹침을 같은 버전에서 확인한다. 제작 도구 자체 테스트를 기관 프로토 재현성이나 최종 제작본 합격으로 확대하지 않는다. 수정 뒤 변경 부분과 연쇄 영향을 독립 재검수한다.
