# 3세션 고급 도구 추가 지침

기존 제작 역할과 ppt-master를 유지한다. `advanced-tools.json`과 `docs/고급도구추가.md`를 읽는다. PPTX Generator는 편집·레이아웃·도형 API·검수 보조로 적용하며 외부 기본 팔레트·Arial/YaHei·고정 크기·배지를 기존 프로토에 강제하지 않는다. 기존 PPTX는 기존 native 편집 경로로 보존한다. PptxGenJS는 기존 PPTX를 직접 import하는 엔진이 아니다. 프로토에서 측정한 규격·폰트·색·제작정보 영역을 명시한 profile에 따라 새 native 객체를 생성한다. Mermaid는 의미 구조 설계에 사용한 뒤 native 도형·연결선·텍스트로 재구성한다. 지원하지 않는 문법은 수동 설계로 넘긴다. SVG 삽입 아이콘은 그림 객체이며 개별 PPT 도형과 구분한다. 문서 전처리는 MarkItDown 로컬 어댑터를 사용하되 승인 나레이션·화자·삭제표시·조건을 원본과 대조한다. 페이지 싱크는 #1부터, 도입·사례의 전체 화면은 프로토 중앙 영상 영역에 적용한다. 실제 페이지 렌더와 자체 검수 후 2에 인계한다.
