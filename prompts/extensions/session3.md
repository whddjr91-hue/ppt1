# 3세션 고급 도구 추가 지침

기존 제작 역할과 ppt-master를 유지한다. `advanced-tools.json`과 `docs/고급도구추가.md`를 읽는다. PPTX Generator는 편집·레이아웃·도형 API·검수 보조로 적용하며 외부 기본 팔레트·Arial/YaHei·고정 크기·배지를 기존 프로토에 강제하지 않는다. 기존 PPTX는 기존 native 편집 경로로 보존한다. PptxGenJS는 기존 PPTX를 직접 import하는 엔진이 아니다. 프로토에서 측정한 규격·폰트·색·제작정보 영역을 명시한 profile에 따라 새 native 객체를 생성한다. Mermaid는 의미 구조 설계에 사용한 뒤 native 도형·연결선·텍스트로 재구성한다. 지원하지 않는 문법은 수동 설계로 넘긴다. SVG 삽입 아이콘은 그림 객체이며 개별 PPT 도형과 구분한다. 문서 전처리는 MarkItDown 로컬 어댑터를 사용하되 승인 나레이션·화자·삭제표시·조건을 원본과 대조한다. 페이지 싱크는 #1부터, 도입·사례의 전체 화면은 프로토 중앙 영상 영역에 적용한다. 실제 페이지 렌더와 자체 검수 후 2에 인계한다.

## 심리 프로토의 도식·원형·블릿·아이콘 실제 활용 (사용자 피드백 2026-10-28)
- 장면 설계 시 실제 심리 프로토의 원형/타원, 말풍선, 블릿/체크, 개념·행동 아이콘, 연결선·화살표·괄호를 찾아 의미에 맞게 활용한다. 사용자가 첨부한 통계학 화면은 보조 표현 예시이며 심리 원본과 기관 양식의 우선순위는 유지한다.
- 항목 묶음은 원형/타원과 공통 연결선·괄호로 묶고 상위 의미/결론을 붙인다. 개념 비교는 대비 기준과 차이를, 과정은 아이콘+짧은 행동 라벨+화살표를, 주체의 설명은 말풍선을, 동등한 점검 사항은 블릿/체크를 활용한다.
- 키워드에는 대상·행동·조건·판단 등 이해에 필요한 문맥을 남긴다. 원만 반복하거나 문장을 여러 상자에 나누거나 아이콘을 장식으로 붙이는 것을 도식화의 완료 근거로 삼지 않는다. 모든 페이지에 같은 요소를 강제로 넣지 않는다.
- 원형의 채움·윤곽선, 말풍선 모양, 블릿 크기/들여쓰기, 아이콘 화풍·색·크기, 강사 좌우 배치와 주황 판단 강조는 해당 프로토의 실제 객체/측정을 따른다. 적합한 원본 객체는 native 구조로 재사용하고 새 디자인으로 임의 교체하지 않는다.
- 장면 계획에 기준 프로토 페이지 / 선택한 도형·블릿·아이콘 / 요소 사이 관계 / 강사와의 배치 / 실제 싱크 타깃 / 출처·권리 / 적합한 시각 요소를 쓰지 않은 사유를 기록한다. 2에 실제 구현 화면을 인계한다.
- 도형·텍스트·연결선은 편집 가능하게 유지한다. 그림/SVG 아이콘의 편집 범위는 별도로 밝히며 기존 아이콘의 제공처·개별 ID/URL·권리를 확인한다. 원본의 검토용 빨간 박스·노란 메모·임시 #0·잘림은 복제하지 않는다.
