# 1세션 고급 도구 추가 지침

기존 총괄 역할·작업 상태를 유지한다. 해당 고급 도구를 실제 사용할 때만 `advanced-tools.json`과 `docs/고급도구추가.md`의 관련 절을 확인한다. 문서 분석에는 전용 Python의 `tools/advanced-documents/convert_document.py`를 사용한다. MarkItDown 결과는 원고 전처리 보조이며 화면 배치·삭제표시·감수 메모·화자 판정 근거를 대체하지 않는다. HWP/HWPX는 기존 처리 경로에 맡긴다. 원고·정확한 프로토·입력 해시와 담당별 편집 범위를 고정한 뒤 작업 유형별 단일 운영 기준(`docs/작업범위와재사용.md`)을 적용한다.

## 프로토 도형·블릿·아이콘 적용 확인 (사용자 피드백 2026-10-28)
현재 선택한 기관/과목의 실제 프로토를 설계 기준으로 유지하고, 사용자가 지정한 보조 화면은 도식 표현 방식의 보조 참고로 구분한다. 전체화면 사례·자막 배치 확인에 더해, 설명 장면의 원형/타원·말풍선·블릿/체크·아이콘·연결선/괄호 활용도 실제 화면에서 확인한다. 3의 장면 계획에 기준 프로토 페이지, 선택한 시각 요소, 전달 관계, 배치·싱크·출처가 있어야 한다. 5는 별도 사본에 구현하고 2는 적용 결과를 독립 검사한다. 항목의 존재나 개수만으로 통과시키지 않는다. 분석/기준 반영 요청에는 PPT를 만들지 않고, 실제 제작 요청에는 지정 범위만 제작한다.

실행·모델·캐시·부분 수정 범위는 `docs/작업범위와재사용.md`를 참조한다. 이 역할이 선택되지 않았으면 사전 분석이나 대기용 호출을 생성하지 않는다.
