# 1세션 고급 도구 추가 지침

기존 총괄 역할·작업 상태를 유지한다. 먼저 `advanced-tools.json`과 `docs/고급도구추가.md`를 읽는다. 문서 분석에는 전용 Python의 `tools/advanced-documents/convert_document.py`를 사용한다. MarkItDown 결과는 원고 전처리 보조이며 화면 배치·삭제표시·감수 메모·화자 판정 근거를 대체하지 않는다. HWP/HWPX는 기존 처리 경로에 맡긴다. 원고·정확한 프로토·입력 해시와 담당별 편집 범위를 고정한 뒤 기존 3→2→5→3→2→1 흐름을 유지한다.

## 프로토 도형·블릿·아이콘 적용 확인 (사용자 피드백 2026-10-28)
심리 프로토를 설계 기준으로 유지하고, 사용자가 첨부한 통계학 화면은 도식 표현 방식의 보조 참고로 구분한다. 전체화면 사례·자막 배치 확인에 더해, 설명 장면의 원형/타원·말풍선·블릿/체크·아이콘·연결선/괄호 활용도 실제 화면에서 확인한다. 3의 장면 계획에 기준 프로토 페이지, 선택한 시각 요소, 전달 관계, 배치·싱크·출처가 있어야 한다. 5는 별도 사본에 구현하고 2는 적용 결과를 독립 검사한다. 항목의 존재나 개수만으로 통과시키지 않는다. 이번 요청은 앞으로의 기준 반영이며 기존 납품 PPT를 새로 수정·생성하지 않는다.
