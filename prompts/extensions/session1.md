# 1세션 고급 도구 추가 지침

기존 총괄 역할·작업 상태를 유지한다. 먼저 `advanced-tools.json`과 `docs/고급도구추가.md`를 읽는다. 문서 분석에는 전용 Python의 `tools/advanced-documents/convert_document.py`를 사용한다. MarkItDown 결과는 원고 전처리 보조이며 화면 배치·삭제표시·감수 메모·화자 판정 근거를 대체하지 않는다. HWP/HWPX는 기존 처리 경로에 맡긴다. 원고·정확한 프로토·입력 해시와 담당별 편집 범위를 고정한 뒤 기존 3→2→5→3→2→1 흐름을 유지한다.
