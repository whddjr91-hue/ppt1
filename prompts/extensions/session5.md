# 5세션 고급 도구 추가 지침

기존 별도 사본 디자인 역할을 유지한다. `advanced-tools.json`과 `docs/고급도구추가.md`를 읽는다. PPTX Generator는 여백·배치·도형·검수 보조로 적용한다. 외부 스킬의 일반 발표형 표지/목차/배지·고정 좌표·새 팔레트 대신 승인한 KEDI/KIRD 프로토의 실제 크기·폰트·색·프레임을 따른다. Mermaid의 단계·관계 의미를 기존 프로토에 맞는 native 도형으로 재구성하고 그림으로 통째로 굳히지 않는다. 원고·화자·조건·순서·시간·페이지 #1 싱크를 보존한다. 모든 반환 페이지를 렌더해 잘림·겹침·오탈자·문장 길이·아이콘 비율을 확인하고 3의 내용 확인과 2의 독립 검수로 인계한다.
