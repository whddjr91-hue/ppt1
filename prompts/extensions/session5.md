# 5세션 고급 도구 추가 지침

기존 별도 사본 디자인 역할을 유지한다. `advanced-tools.json`과 `docs/고급도구추가.md`를 읽는다. PPTX Generator는 여백·배치·도형·검수 보조로 적용한다. 외부 스킬의 일반 발표형 표지/목차/배지·고정 좌표·새 팔레트 대신 승인한 KEDI/KIRD 프로토의 실제 크기·폰트·색·프레임을 따른다. Mermaid의 단계·관계 의미를 기존 프로토에 맞는 native 도형으로 재구성하고 그림으로 통째로 굳히지 않는다. 원고·화자·조건·순서·시간·페이지 #1 싱크를 보존한다. 변경 페이지와 공용 리소스의 직접 영향 페이지를 렌더해 잘림·겹침·오탈자·문장 길이·아이콘 비율을 확인하고 3의 내용 확인과 2의 독립 검수로 인계한다. 파일·의존성·렌더러/폰트·규칙 해시가 같은 미변경 페이지는 기존 실제 관측 근거를 연결하며 무수정 사본의 재렌더/재검수를 반복하지 않는다.

## 프로토 시각 요소의 재사용과 배치 (사용자 피드백 2026-10-28)
심리 프로토의 실제 원형/타원·말풍선·블릿/체크·아이콘·연결선·괄호를 디자인 보완에 활용한다. 첨부 통계학 화면은 묶기·비교·과정·강조의 보조 참고이며 심리 프로토를 대체하지 않는다. 원형은 항목 묶음/분류와 공통 판단, 말풍선은 주체와 설명, 아이콘+라벨+화살표는 행동/순서, 블릿/체크는 동등한 점검 사항에 맞춰 선택한다.
원본의 윤곽선·채움·색·서체·블릿 위계·아이콘 화풍과 크기·강사 좌우 배치를 유지하고 의미를 전달하는 관계를 보완한다. 적합한 기존 객체를 재사용하며 내용과 무관한 아이콘·동일 원 반복·문장 상자 나열을 피한다. 원형이나 아이콘 안에도 이해 가능한 라벨을 둔다. 원본 검토 표시·임시 번호·잘림은 적용 대상에서 제외한다.
반환 전 3의 장면별 적용 계획과 실제 객체를 대조하고 선택 요소/관계/배치/싱크/출처를 변경 기록에 남긴다. 2에 실제 렌더를 넘기며 적용했다는 설명만으로 완료 처리하지 않는다. 텍스트·도형은 native 편집성을 지키고 이미지/SVG 아이콘과 그 권리는 구분한다.
