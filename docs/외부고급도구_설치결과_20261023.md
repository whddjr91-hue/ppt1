## 보존한 기존 상태

- `AGENTS.md`, `.codex/config.toml`, 기존 스킬 원본, 원래 source-lock, 기존 초기화 스크립트·기준 문서는 변경하지 않았다.
- 비교에 필요한 기존 17파일 중 기준/설정/스킬 12파일은 원격 원본과 byte 동일하다. 역할 프롬프트 5개는 원래 전체 내용을 그대로 두고 추가 지침 포인터 한 줄만 붙였다.
- 기본 새 자동등록은 MiniMax 1개다. PDF·CLI는 동일 기능 중복 등록을 피했다. 기존 등록 경로가 다르면 설치 도구는 덮어쓰지 않고 중단한다.
- 기존 원고·참고 PPT·완성본·백업·세션 레지스트리·인증정보를 변경하거나 새로 제작하지 않았다. 임시 파일 정리 뒤 GitHub에서 비교용 지침만 읽었으며, 과거 작업 폴더 전체 복원 작업을 다시 수행하지 않았다.
- 이번 작업은 기존 ppt-master 실행 검증을 다시 수행한 것이 아니다. 현재 비교용 사본에 attribution guard가 없어 실행을 중단했으며 gate를 우회하거나 원본을 수정하지 않았다. GitHub의 기존 전체 스킬 파일은 유지한다.

## 실제 검증의 범위

제작 진단에는 실제 기관 원본 대신 명시적으로 표시한 가상 KEDI/KIRD 규격을 사용했다. 진단용 4쪽의 한글·표·차트·아이콘·관계도·싱크와 실제 PDF/PNG를 확인했다. 실제 기관 프로토와 100% 동일하다는 판정이나 새 콘텐츠 납품본 완성 판정은 하지 않는다.

전용 제작 라이브러리는 native 텍스트·도형·표·차트를 생성한다. SVG 아이콘은 원본 SVG와 PNG 미리보기를 함께 보존하는 그림 객체이므로 개별 PPT 도형 편집과 구분한다. Mermaid 구조는 native 도형·텍스트·연결선으로 재구성한다. 로컬 sharp만 사용한 SVG 출력 경로도 실행했다.

설치 도구의 실제 보호 테스트는 기본 중복 등록 회피, 반복 실행 시 동일 내용 유지, 다른 기존 스킬을 덮어쓰지 않는지 확인한다. `tests/test_advanced_tools.py`의 3개 테스트가 통과했다. 독립 검수에서 발견한 좌표 옵션 우회와 페이지 첫 싱크 누락 검증도 보완했으며 관련 부정 입력 50건을 확인했다. 기존 진단 PPTX/PDF/PNG 8개의 해시는 그대로 유지됐다. 통합 검수 결과는 `tests/advanced-tools-review.json`, 요약은 `tests/advanced-tools-results.json`에 보관했다. 제작 진단·원고 처리·브라우저/문서 도구의 세부 범위와 한계는 각 `integration-result.json`에 기록했다.

## 라이선스와 출처

MiniMax 원본은 commit `60aaae52bb2af8162732751a4332f62a5fef518b`, OpenAI 원본은 commit `49f948faa9258a0c61caceaf225e179651397431`에 고정했다. 원본 SKILL.md와 부속 파일은 바꾸지 않고 라이선스·NOTICE·출처를 함께 보관했다. MarkItDown 문서 확인 commit은 `7482c092d9c0074a89803c9fdb63a969e7fe17fc`이며, 설치한 PyPI 배포판의 동일성은 별도 requirements.lock 해시로 확인한다. 문서 commit을 배포판 빌드 commit으로 단정하지 않는다.

주 도구 라이선스는 MiniMax/PptxGenJS/Mermaid/MarkItDown MIT, OpenAI 스킬 Apache-2.0이다. 보조 패키지의 원문 고지는 제작 tools/licenses 및 설치된 패키지에 보존한다. 의존성 바이너리·node_modules·가상환경·독립 폰트·캐시·브라우저 파일은 GitHub에 올리지 않고 lock/설정/코드만 저장한다.

## 다음 제작 적용

기존 1~5세션 역할과 **3 제작 → 2 검수 → 5 디자인 → 3 내용 확인 → 2 재검수 → 1 최종 통합**을 유지한다. 추가 지침은 각 역할 프롬프트와 `advanced-tools.json`에 연결했다. 원고·정확한 참고 프로토·수정 범위를 지정하면 승인한 디자인에 맞춰 새 도구를 보조적으로 사용한다. 실제 기관 프로토 파일의 경로·해시·크기·색·글꼴·제작정보 영역을 먼저 확인한다.

추가 도구 확인과 선택 설치 명령은 [고급도구추가.md](고급도구추가.md)에 있다. 기존 프로젝트를 처음부터 초기화할 필요가 없다. Chromium 후속 설치와 API 캡처는 완료했다. CLI daemon의 소켓 제한과 외부 사이트별 접근 조건은 남아 있으며, 사용법은 tools/advanced-browser/README.md를 따른다.
