# 프로젝트 자료를 다른 컴퓨터로 옮길 때

이 공개 저장소는 운영 기준·설정·연결 도구를 옮긴다. 실제 원고와 참고 PPT·촬영 컷·스톡·글꼴·완료본은 별도 자료다. 로그인 파일이나 기존 세션의 실제 연결 로그도 포함하지 않는다.

필요한 자료를 개인 저장장치 또는 허용된 비공개 보관소에서 옮긴 뒤, 다음 상대경로를 맞춘다. 공개 업로드 여부와 자료 사용권은 별도로 판단한다.

```text
참고자료/       선택한 KEDI/KIRD 양식·관련 문서
참고 사진/     사용자가 직접 기준으로 지정한 화면 예시
작업파일/       원고·감수의견서
보완(1)/       해당 프로젝트 보완 요청
프로젝트/<이름>/ 제작본·시각자료·출처근거·보고·검수·산출물
```

기존 파일은 보존하고 새 복원 작업은 별도 사본으로 한다. 같은 이름의 최신본을 추정하지 말고 제공된 검증 기록의 해시로 확인한다. 운영 설정만 옮긴 경우 실제 프로젝트 파일이 준비됐다고 주장하지 않는다.

KIRD 역사학 프로젝트의 합의 설정은 `프로젝트설정/KIRD_역사학_연구윤리.json`에 있다. 이 파일에는 원고나 이미지가 없으며, 완료 당시의 식별값을 새 PC에서 검수했다는 뜻도 아니다. 필요한 실제 자료를 준비한 뒤 총괄이 입력을 재확인한다. 과거 승인 기록을 새 원고·새 자산에 대한 포괄 승인으로 확대하지 않는다.

이전 컴퓨터의 대화 목록·계정 로그인·앱별 연결 권한은 저장소 파일로 복원되지 않는다. 새 대화를 등록하고 실제 수신 시험을 한다. 이전 대화가 계정에 보이더라도 새 PC에서 그 대화와 작업 폴더가 연결됐는지 따로 확인한다.
