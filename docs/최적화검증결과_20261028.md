## 세션별 결과

1은 범위·대표 페이지·필수 검수·최종 파일을 결정한다. 2는 반복 구조 검사를 로컬 코드로 수행하고 변경 부분의 의미/시각을 독립 판단한다. 3은 원본 객체 재사용과 승인 계획/실제 출력의 대본·화면 대상 검사를 연결한다. 4는 신규 조사에만 실행한다. 5는 부분 작업의 실제 디자인 결함 또는 전체 제작의 독립 디자인 검사에 실행하며, 결함이 없으면 수정 없이 채택한다.

이번 시스템 작업의 추가 에이전트 작업 시작은 구현2회·검수2회, 총4회였다(총괄 외 기존 역할2·3만 사용,4·5 미실행). 이는 이 작업의 관측된 작업 시작 수이며 토큰/과금 로그가 아니다. 개선 전 동등 작업의 실제 호출·토큰 로그는 없으므로 비용 비교의 기준으로 사용하지 않았다.

## 유지한 품질 기준과 한계

원고·조건·화자·순서·싱크·출처/권리·native 편집성, 실제 동일 역할 프로토와의 비교, 가독성/정렬, 대상·행동·관계·조건·판단의 직접 관측을 유지했다. 원형/아이콘 개수·파일 생성·캐시 적중·자동 계약은 교수설계 합격이 아니다. 전체 생산은 현 원고·계획의 대표 case/diagram 실물 검수 근거를 요구한다. 승인된 페이지는 근거 없이 재설계하지 않는다.

예상 효과는 불필요한 역할 호출/자료 재추출/전체 재생성/근거 없는 수정의 감소다. **실제 토큰·크레딧 로그가 없어 과금 절감률과 동일 비용 대비 새 원고 품질 향상은 측정하지 못했다.** 사용량 기록기는 실제 provider 로그가 없으면 null을 보존한다.

추가 검증이 필요한 사항:

- 새 원고로 설계한 대표2~3쪽의 교수설계·디자인 채택과 실제 사용량 비교. 위3쪽은 기존 페이지 보존 시험이므로 이를 대신하지 않는다.
- 실제 Codex/VS Code 실행기의 새 model/reasoning 적용. 카탈로그 지원/TOML 문법은 확인했으나 이 호스트에 Codex CLI가 없어 CLI 세션 실행은 검증하지 않았다. 기존 열린 세션은 변경되지 않는다.
- 기존 Mermaid/가상 진단 Node 경로의 고정 의존성이 이 checkout에 없으므로 그 전체 진단은 이번에 재실행하지 않았다. 엔진 소스/lock은 변경하지 않았고, 새 native 재사용 경로는 새 의존성 설치 없이 실행했다.
- PowerPoint 앱의 열기/재저장, MP4/음성 전체 재생, 신규 권리 취득은 검증하지 않았다. 원본의 워터마크/기존 미디어를 보존한 것이 사용권 취득은 아니다.
- native 복제는 정확 텍스트 교체·레이아웃 보존 범위다. 복잡한 새 도식 설계는 기존 native 편집 경로와 사람의 판단이 필요하다. 간접/모호한 cross-slide 링크는 추측 복구하지 않고 거부한다.
- 수정 회수 기록과 라우팅 계획은 이를 따르는 호출기에 적용된다. 외부 호스트의 모든 호출을 강제로 제어하는 전역 스케줄러는 아니다. 기존 등록 스킬/열린 세션에 자동 배포됐다고 주장하지 않는다.

프로젝트 원고·PPT·렌더·로컬 카탈로그·진단 산출물·인증 정보는 이 변경에 포함하지 않았다. 초기 checkout의5개 CRLF 정규화 차이는 이번 변경과 무관하여 제외했다.
