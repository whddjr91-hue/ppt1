# 공통 스킬과 실행 환경

스킬 원본 5개는 기존 공개 도구 저장소 `csi20140104-ops/ppt-12`를 사용한다. `source-lock.json`에 원본 commit과 manifest 해시를 고정했다. `Fetch-SourceSkills.ps1`가 `.local/skill-source/`에 복원하고 라이선스를 보존한다. `Initialize-Workspace.ps1`는 해당 원본을 가리키는 `.agents/skills/` 연결을 만든다. 기존 컴퓨터의 절대경로가 들어간 junction 자체는 Git에 올리지 않는다. 이미 저장소 루트에 `.claude/skills/` 원본 5개가 있으면 그 경로를 사용할 수 있다.

| 저장소 스킬 | 용도 |
|---|---|
| grill-me / grilling | 사용자가 원한 계획·아이디어 인터뷰/검토 |
| playwright-skill | 브라우저 자동화·검증 |
| ppt-master | PPT 제작 워크플로 |
| pptx | PPT 읽기·생성·수정·검증 |

도구 실행 전에 관련 `SKILL.md`를 읽는다. 원본 라이선스를 보존하고 사용자 지시·기준 양식을 우선한다. 스킬 등록은 Python/Node·패키지·브라우저·렌더러 설치나 실행 성공을 의미하지 않는다. 원본의 요구 의존성을 확인한 뒤 필요한 것만 설치한다. 캐시·node_modules·가상환경·브라우저 프로필은 옮겨 적지 않는다.

다음 스킬은 현재 컴퓨터의 Codex 기본 제공 또는 플러그인 연결로 별도 확인한다: imagegen, openai-docs, skill-creator, skill-installer, plugin-management, sites, work-pets(create-pet/pets/update-pet). 제공 계정/버전/권한은 컴퓨터마다 다르므로 개인 플러그인 캐시를 저장소에 복제하지 않는다. 기존 사이트·동물 캐릭터·이미지 생성 작업을 스킬 목록이 있다는 이유만으로 실행하지 않는다.

새로 등록한 뒤 Codex의 실제 스킬 목록을 확인한다. 갱신되지 않으면 진행 중 작업을 저장한 뒤 VS Code `Developer: Reload Window`를 사용할 수 있다. 다른 창에서 로드됐는지는 그 창의 실제 목록이나 담당 보고로 확인한다.

사용자 모델 선호는 `gpt-6.1-sol` / `high`다. 저장소 설정은 선호를 지정하며 계정의 모델 이용 가능 여부·잔여 한도·각 별도 대화의 실제 선택을 보장하지 않는다. 이용할 수 없거나 한도가 소진됐다는 이유로 다른 모델로 임의 전환하지 않는다.
