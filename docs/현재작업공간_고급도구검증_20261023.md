## 보존과 검증 근거

- `Manage-AdvancedTools.py check`: 원본 24파일 해시, 기존 17파일/프롬프트 원문 보존, 문서/제작/CLI 실행 환경 확인 통과.
- 추가 도구 원본은 MiniMax commit `60aaae52bb2af8162732751a4332f62a5fef518b`, OpenAI commit `49f948faa9258a0c61caceaf225e179651397431`과 대조했다. OpenAI 해당 저장소는 deprecated 안내가 있어 최신 권장 컬렉션이라고 표현하지 않는다.
- 현재 원본 KEDI 176쪽·KIRD 73쪽을 읽기 전용 구조 분석했다. 실제 크기와 그룹 자식을 확인하고 분석 전후 원본 SHA256이 같음을 확인했다. 새 진단용 가상 규격과 실제 프로토 동일성을 혼동하지 않는다.
- 기존 실제 원고·프로젝트 완료본은 재제작하지 않았다. 이후 선택한 원고/프로토마다 편집성·싱크·레이아웃·출처·동일 해시 렌더를 다시 확인해야 한다.
- 현재 2·3·4·5 내부 에이전트가 최신 canonical 추가 지침을 읽고 준비 확인을 기록했다. 총괄은 1세션 역할로 취합한다.
- 별도 설치 시험에서 복잡한 Mermaid SVG의 직접 삽입 렌더 실패를 발견했고 native 흐름도로 수정한 2쪽을 독립 재검수했다. 활성 canonical 엔진도 native 흐름도를 생성한다.
- 설치 바이너리·node_modules·가상환경·브라우저 캐시·인증정보·백업·기존 산출물은 이번 검증 커밋에 포함하지 않는다.

## 실행 범위의 한계

PPTX native 구조와 렌더 시험은 실제 PowerPoint/한글 앱 편집·재저장 또는 애니메이션·영상·음성 재생 검증이 아니다. HWP/HWPX의 MarkItDown 지원을 주장하지 않으며 기존 처리 방식을 유지한다. 브라우저 CLI 존재와 실제 캡처 가능 여부를 구분하고 현재 환경의 브라우저 정책을 따른다. 기관 감수·미디어 공개 사용권·사용자 최종 디자인 수용도 별도다.
