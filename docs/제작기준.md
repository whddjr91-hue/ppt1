# 제작 기준

## 시작 인터뷰

사용자가 프로젝트의 주제와 대상 등을 대략 지정한다. 총괄은 주제·대상·학습 목적부터 확인하고 다음 항목을 단계적으로 구체화한다. 한 번에 관련 질문 2~3개 이하로 묻고 이미 받은 답변은 다시 묻지 않는다.

- 원고·감수 의견·제공 자료와 신규 집필 범위
- KEDI/KIRD 중 기준 양식과 정확한 참고 파일
- 목표 길이·편수·화면 비율·촬영/성우/강사 혼합 방식
- 내레이션·자막·싱크·화면/촬영/그래픽/음향 지시 범위
- 산출물·일정·권리·검수 조건

확정값, 제안, 가정을 분리한다. 원고나 사용자가 특정하지 않은 프로젝트를 임의로 시작하지 않는다.

## 양식과 원고

선택한 PPT를 실제 화면으로 분석한다. KEDI/KIRD 모두 16:9여도 슬라이드의 인치 규격은 다를 수 있으므로 원본의 실제 크기를 보존한다. 중앙 영상 시안, 주변 제작 정보, 내레이션, 자료/싱크란의 위치와 표·도형·색·글꼴을 따른다. 다른 참고 PPT는 보조로 명시한다.

원고의 활성 본문, 감수 메모, 취소선, 후속 의견을 구분한다. 원고 보존 원칙과 사용자 승인 예외를 함께 기록한다. 문단→장면→내레이션/화자→화면 핵심어→싱크/제작 지시→출처를 추적할 수 있어야 한다. 사례의 조건·행위 주체·비판 귀속·판정 유보를 화면 축약 과정에서 빼지 않는다.

## 사례와 시각 자료

프로젝트에 합의된 경우 소주제 첫 사례·조건부 상황은 중앙 영상 영역 전체 이미지/영상으로 구성한다. 일반 활용 설명을 새 실제 사건으로 만들거나 원래 강사 음성을 성우로 임의 변경하지 않는다. 정리하기는 합의된 마지막 페이지에 두고 기존 낭독문과 순서를 보존한다.

자료에는 제공처·개별 URL·ID·작가 확인 범위·확인일·사용권 상태를 남긴다. 생성/자체 제작 자료는 도구·제작일·프롬프트나 제작 코드·승인 기록을 연결한다. 일반 스톡/설명용 재현과 실제 사건 증거를 구분한다. 영상 정지컷이면 정지컷·MP4 확보/삽입/전체 재생 여부를 각각 기록한다.

공개 미리보기를 최종 사용권이 있는 자료로 취급하지 않는다. 워터마크 유지, 접근 차단/미확보, 실제 원본 정보량과 캡처 확대 해상도를 구분한다. 승인된 선별/삽입 범위의 작업은 진행하고 새로운 연출이나 중요한 범위 변경만 총괄이 사용자에게 묻는다.

세부 프로젝트값은 `templates/project.json`으로 시작하고 `프로젝트설정/`의 예시를 참고한다. 원고·참고 파일은 별도로 준비한다.
