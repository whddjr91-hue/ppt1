# 실제 프로토에서 확인한 설계 원리

KIRD 심리 v1.4 73페이지와 원고 v2.0, 통계 완성본 v1.2 97페이지의 재분석이다. 현재 사용자가 선택한 프로토와 승인 원고가 우선한다.

| 역할 | 원본 예 | 적용 원리 |
|---|---|---|
| 사례 | 심리16~23p 온라인 실험,45~47p 상담기록,57~59p AI 자극 | 상황·대상·행동·빠진 절차를 차례로 보여주고 뒤의 판단 근거로 삼는다. |
| 동의 조건 | 심리32p | 버튼과 이해 가능한 핵심 정보·자발적 결정의 관계를 함께 보여준다. |
| 서로 다른 판단 | 심리40~41p,51p,65p | 분석 제외/보상 미지급, 상담 동의/연구 활용 동의, 필수/비필수 조건을 구분한다. |
| 계층·판단 | 심리50p | 상담기록의 정보 종류를 묶어 식별 가능/민감정보와 보호 필요성을 연결한다. |
| 조작점검 | 심리66p | 연령 조건과 표정·자연스러움·품질을 다른 검사 대상으로 구분한다. 아이콘·라벨·하단 판단이 대응한다. |
| 기록 항목 | 심리69p | 프로그램/버전·프롬프트/설정·시점·수·편집 여부를 다른 아이콘·싱크로 표현한다. |
| 핵심 판단 | 심리71p | 산출물·검토할 후보·타당성/한계·연구 채택·연구자 책임의 의미를 남긴다. |
| 원인결과 | 통계24p | 선택적 보고와 증거 강도 과장을 연결하고 판단을 제시한다. |
| 개념 구분 | 통계25~26p,36p | 분석 반복/선택 은폐와 사후 가설, 탐색 패턴과 독립 검증을 구분한다. |

## 원고와 전개
- 온라인 사례는16~23p, 판단 기준24~42p, 퀴즈43p다.
- 상담 사례는45~47p, 판단 기준48~54p, 퀴즈55p다.
- AI 사례는57~59p, 판단 기준60~71p, 부가자료72p, 마무리73p다.
- 문장마다 같은 카드를 만드는 규칙이 아니다. 승인된 순서·화자는 임의 변경하지 않는다.

## 실제 위계와 측정
심리 원본은10×5.625인치다. 중앙 영상 영역은 대략 x1.43,y0.73,w6.75,h3.76인치이며 현재 원본을 다시 측정한다. 화면의 주된 서체는 나눔바른고딕이고 일부 말풍선은 나눔고딕이다. 대표 페이지에서 소주제10pt, 도식 라벨12~16pt, 큰 사례/판단 문장28~31pt를 확인했다. 이를 모든 기관/장면의 고정값으로 적용하지 않는다.

소주제 표시·핵심 표현·보조 설명·제작정보/자료란은 다른 위계다. 매장 큰 제목 띠와 단일 글꼴로 통일하지 않는다. 강사 배치와 인물 생략도 정보량·관계에 따라 결정한다.

## 반복하지 않을 실패
- ‘8개 연구기관/저항0·마이스너 효과 확인 안 됨’만 남기고 검증 대상·행동·판단 귀속을 생략하지 않는다.
- 같은 이름의 원8개로 검증 과정을 설명했다고 하지 않는다.
- 관련 없는 장비 사진으로 사례를 꾸미거나, 이를 고친다며 논문/기사 전체를 붙여 보고서처럼 만들지 않는다.
- 명사 축약으로 비교·조건·결론을 없애거나 모든 원고를 화면에 복사하지 않는다.
- Mermaid 파싱은 문법/입력 구조 확인이다. 실제 화면의 관계 전달과 동일하지 않다.
- 원고 일치·출처·겹침·CRC가 통과해도 의미가 불명확하면 반려한다.

## 확인 범위
73페이지 전체 전개와 대표 화면을 분석했다. HWP는 본문 추출로 읽었으며 정확한 페이지 구분/앱 렌더 검증은 아니다. 원본 임시 메모·#0·줄바꿈 오류는 새 기준으로 복제하지 않는다. 심리 원본에는 native timing/삽입 MP4가 없으므로 번호/미리보기만으로 실제 재생 완료를 주장하지 않는다.
