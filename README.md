# 이러닝 PPT 스토리보드 작업 환경

제작 기준, Codex 설정, 실제 1~5세션의 역할과 인계 절차를 다른 컴퓨터에서 이어 쓰기 위한 저장소다. 업로드 대상은 `whddjr91-hue/ppt1`이다. 스킬 원본은 `source-lock.json`에 고정한 별도 원본 저장소에서 로컬로 복원하고, 각 원본의 라이선스를 유지한다.

## 다른 컴퓨터에서 시작

1. 이 저장소를 clone하거나 전체 ZIP을 내려받아 푼다.
2. VS Code와 Codex 확장(`openai.chatgpt`)을 설치하고 본인 계정으로 로그인한다.
3. VS Code에서 **저장소 루트 폴더**를 연다. 신뢰할 수 있는 프로젝트인지 확인한 뒤 프로젝트 설정을 사용한다.
4. PowerShell에서 `./scripts/Fetch-SourceSkills.ps1`로 고정 버전의 스킬 원본을 복원한다. 이어 `./scripts/Initialize-Workspace.ps1 -CheckOnly`로 준비 상태를 확인하고, `./scripts/Initialize-Workspace.ps1`로 스킬 연결과 로컬 레지스트리를 만든다.
5. 1~5세션을 만들고 [역할별 시작 메시지](prompts/)를 각 대화에 보낸다. 실제 세션 UUID를 등록하고 수신 시험을 마친 뒤 연결을 사용한다.

자세한 명령은 [새 컴퓨터 설정](docs/새컴퓨터설정.md)에 있다. 실행 정책·조직 정책으로 차단되면 임의로 완화하지 않고 환경 담당자 또는 총괄에게 오류를 전달한다.

## 역할

| 세션 | 주 업무 |
|---|---|
| 1 | 총괄·사용자 인터뷰·배분·충돌 조정·최종 보고 |
| 2 | 내용·화면·출처·구조의 독립 검수와 수정 요청·재검수 |
| 3 | 원고·장면 구성·스토리보드 PPT 제작·디자인 반환의 내용 확인 |
| 4 | 사진·영상·아이콘·글꼴·출처와 사용권 조사 |
| 5 | 별도 사본 디자인·서체·배치·가독성 보완 |

흐름: **자료4 지원 / 제작3 →검수2 →디자인5 →반영 확인3 →재검수2 →총괄1 통합**.

## 들어 있는 것

- `AGENTS.md`: 모든 세션의 공통 운영 기준
- `.codex/config.toml`: `gpt-6.1-sol` / `high` 선호 설정
- `docs/`, `prompts/`, `templates/`: 제작·검수 기준, 역할별 시작 메시지, 인계/프로젝트 양식
- `scripts/`: 이 컴퓨터의 스킬 등록·세션 연결 도구
- `프로젝트설정/`: 원고를 포함하지 않은 KIRD 역사학 프로젝트의 합의 설정

## 별도로 이전할 것

원고·참고 PPT·사진·완료 PPT와 HWPX·스톡/글꼴 파일은 이 공개 운영 패키지에 포함하지 않는다. 필요한 작업 자료는 권한을 확인해 별도로 옮기고 [프로젝트 이전 안내](docs/프로젝트이전.md)에 따라 연결한다. 로그인과 기존 대화 이력도 자동 복구되지 않는다. 기존 컴퓨터의 세션 UUID·인증·브라우저 프로필·실제 연결 로그는 업로드하지 않는다.

공식 설정 안내: [Codex 설정 예시](https://learn.chatgpt.com/docs/config-file/config-sample), [IDE 설정](https://learn.chatgpt.com/docs/ide/settings). 스킬 원본의 라이선스와 지침은 각 원본 폴더를 따른다.
