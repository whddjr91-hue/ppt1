# 작업 인계 보고

- 작업 ID / 담당 세션 / 보고 시각:
- 상태와 판정 범위:
- 입력 파일·버전·SHA:
- 실제 완료 내용:
- 산출물 경로·SHA / 같은 버전의 렌더:
- 검사한 내용·실제 화면 범위·근거 파일:
- 해결한 결함 ID / 남은 결함과 담당·영향·완료 조건:
- 보존한 원고·조건·화자·순서·시간·출처:
- 미실시·미확인 사항:
- 총괄 판단 또는 사용자 질문이 필요한 것:
- 다음 단계 / 편집 소유 / 중복 지시 여부:

큐 접수는 실제 수신·작업 완료와 구분한다. 자신이 수행하지 않은 검사와 다른 담당의 판정을 본인 완료로 쓰지 않는다.
